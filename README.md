# Obsessia Privacy Policy

Last updated: May 2026

Obsessia is developed by Kruni Apps.

## Information We Collect

Obsessia may collect and store:

- Email address through Firebase Authentication
- Tracker entries
- Order AI conversation history
- Order session history
- Premium membership status
- Basic app preferences

## AI Features

Messages sent to the Order AI assistant may be processed through OpenAI services to generate responses.

## How Information Is Used

Information is used to:

- Provide app functionality
- Maintain account access
- Save tracker and session progress
- Generate AI responses
- Support premium features
- Improve app stability

## Data Sharing

Obsessia does not sell personal information.

Some data may be processed by third-party services required for app functionality, including:

- Firebase Authentication
- Google Play Services
- OpenAI API

## User Control

Users may delete tracker data and Order sessions inside the app.

Users may request account deletion or privacy support by contacting:

kruniapps@gmail.com

## Children

Obsessia is not intended for children under 13.
